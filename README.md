# Surfside Snaps Website

Static website for Surfside Snaps photo booth rentals.

## Setup

1. Upload `index.html` and the `images/` folder to a GitHub repository.
2. Add these image files inside `images/`:
   - hero.jpg
   - photo_strip.jpg
   - gallery_birthday.jpg
   - gallery_wedding.jpg
   - gallery_party.jpg
   - gallery_event.jpg
   - gallery_friends.jpg
   - beach_footer.jpg
3. In GitHub, go to **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Visit the GitHub Pages URL after deployment.

Booking links use email and telephone links from the supplied HTML.
